To use this example, install `santec_tsl` to a virtual environment and `FreeSimpleGUI`

Example setup:

Within `Santec-TSL/examples`, run

1. `python -m venv venv` to create a virtual environment
2. 'source venv/bin/activate' to activate the virtual (may be different depending on your shell)
3. 'pip install -r requirements.txt'

then launch the GUI with 'python GUI.py'
