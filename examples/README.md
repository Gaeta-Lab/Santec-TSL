To use this example, install `santec_tsl` and `FreeSimpleGUI`

Example setup:

After cloning this repo, go to `Santec-TSL/examples` and run

1. `python -m venv venv` to create a virtual environment
2. `source venv/bin/activate` to activate the virtual environment (may be different depending on your shell)
3. `pip install -r requirements.txt` to install both `santec_tsl` and `FreeSimpleGUI`

then launch the GUI with `python GUI.py`
